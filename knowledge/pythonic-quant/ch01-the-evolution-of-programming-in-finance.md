# Chapter 1 — The Evolution of Programming in Finance

## Core idea
Why software — and Python specifically — became central to modern finance:
from manual calculation to spreadsheets to automated, data-driven systems
that now power trading, risk management, and analysis.

## The progression
- **Manual era**: hand calculations, then **spreadsheets** (Excel) automated
  repetitive work and cut errors.
- **Advanced modeling software**: processing large datasets, real-time
  analysis, automated trading strategies, scenario simulation.
- **Programming languages** — especially Python — bridged manual work and
  full automation: fetching/cleaning data, statistical models, visualization.
- Benefits: tasks that took days now take minutes; algorithms scan millions
  of data points for trends, sentiment, anomalies.
- **Democratization**: open-source tools give individual analysts and small
  firms the same power as large institutions.

## Why Python won
- **Design philosophy**: readability, simplicity, versatility; clean syntax
  lowers the learning curve for finance professionals.
- **Open-source ecosystem**: NumPy (numerics), pandas (data), Matplotlib
  (visualization), SciPy (statistics), scikit-learn/TensorFlow (ML) — all
  free and actively developed.
- **Analysis-to-execution bridge**: models built in Python go directly into
  trading systems without translation between languages.
- **Community + education**: universities teach it; hedge funds and banks
  adopted it for quant analysis, risk, and derivatives pricing.
- **Scalability**: handles the large datasets common in finance.

## Risks of digital finance
- System errors, algorithmic anomalies, cybersecurity threats.
- The digital divide: access to compute and skills is uneven.
- These set up the book's recurring theme: with power comes the need for
  rigor, ethics, and regulation (ch9).
