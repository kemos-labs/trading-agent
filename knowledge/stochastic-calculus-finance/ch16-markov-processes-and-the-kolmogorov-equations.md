# Ch16 — Markov Processes and the Kolmogorov Equations

**Source:** *Stochastic Calculus and Finance* (1997 lecture notes, Part II)
— Steven Shreve

## Stochastic differential equations (SDEs)

```
dX(t) = a(t, X(t)) dt + σ(t, X(t)) dB(t)
```

Existence/uniqueness requires continuity in t and **Lipschitz continuity**
in x: |a(t,x)−a(t,y)| ≤ L|x−y|, |σ(t,x)−σ(t,y)| ≤ L|x−y|. The solution is
adapted to the filtration generated by B (driven only by the observed
shocks).

Classic examples:
- **Drifted Brownian motion**: dX = a dt + dB → X(t) = x + a(t−t₀) +
  (B(t)−B(t₀)) — trivial case.
- **Geometric Brownian motion**: dX = rX dt + σX dB → X(t) =
  x·exp(σ(B(t)−B(t₀)) + (r − σ²/2)(t−t₀)) — verify by Itô (the σ²/2
  correction cancels).

## Markov property for diffusions

Solutions of SDEs are Markov: for 0 ≤ t₀ ≤ t₁,

```
E^{t₀,x}[h(X(t₁)) | F(t₀)] = E^{t₀, X(t₀)}[h(X(t₁))]
```

Only the current value X(t₀) matters for future expectations — the whole
path is summarized by the present. (Conditional on the present, past is
irrelevant.)

## Transition density and Kolmogorov equations

The transition density p(t₀, t₁, x, y) (density of X(t₁) given X(t₀) = x)
satisfies two PDEs:

**Kolmogorov backward equation** (in the *initial* variables):

```
−∂p/∂t₀ = a(t₀,x)·∂p/∂x + ½σ²(t₀,x)·∂²p/∂x²
```

**Kolmogorov forward equation / Fokker-Planck** (in the *final* variables):

```
∂p/∂t₁ = −∂(a p)/∂y + ½∂²(σ² p)/∂y²
```

The forward equation governs how the density of X(t₁) evolves — used for
transition densities, and in finance for density forecasts and
implementing PDE methods.

## Black-Scholes from the PDE side

For v(t,x) = E^{t,x}[h(X(T))] (Feynman-Kac), the backward equation becomes
the Black-Scholes PDE. The connection: expected payoffs of Markov
diffusions solve PDEs. So pricing can be done two equivalent ways —
simulate the SDE (Monte Carlo) or solve the PDE (Black-Scholes) — and the
choice depends on dimension/payoff structure.

## Price-dependent volatility

If σ = σ(S) (local volatility), the same machinery works; the PDE gains
state-dependent coefficients. This is the route to local-vol models
(Dupire): calibrate σ(S,t) to reproduce the observed option surface.

## Key takeaways

- SDE solutions: unique under Lipschitz conditions; Markov by construction.
- GBM solution formula: X(t) = x·exp(σB + (r−σ²/2)t) — memorize the
  σ²/2 drift.
- Kolmogorov backward/forward (Fokker-Planck) equations: transition
  densities solve PDEs in initial/final variables.
- Feynman-Kac: option value = risk-neutral expectation ⇔ solves a PDE;
  Black-Scholes is the prime example.
