# Chapter 16 — Excel Charts: How to Read Them and How to Build Them

Source: Leshik & Cralle, *An Introduction to Algorithmic Trading* (2011)

## Practice

- Charting skill transfers to the OMS and specialist charting programs.
  Limits: 32,000 data points per chart; safely up to ~6 plots per chart.
- Visual analysis is key to the authors' research — e.g., "How does
  %Range vary on 150T blocks in a session?" becomes easy once charting
  is fluent.
- Build: highlight data range → chart icon → Chart Wizard → Line
  ("Line with markers displayed at each data value" is the default sub-
  type); customize axes/scales (e.g., a green SMA−LMA trigger line on a
  secondary right-hand axis because its values are much smaller).

## Key takeaways

1. Charts are the primary analytical interface: price tick line
   (jagged) vs. SMA (smoother) vs. LMA (smoothest); overlay trigger
   lines on secondary axes.
2. Efficient charting reduces the inertia of exploratory questions
   about tick-scale statistics.
