# Chapter 37 — Hardware Specification Examples

Source: Leshik & Cralle, *An Introduction to Algorithmic Trading* (2011)

## Recommended (circa 2010) top-of-line spec

- Most powerful box the budget allows: 2× quad-processor boards,
  ≥16GB RAM; best NVIDIA card driving up to 8 monitors.
- **Solid-state hard drives** (new, expensive, but worth it for speed
  and reliability — the authors' next rig: 2× SSDs). Bootable mirrored
  backup (zero downtime).
- Monitors: 8-way array (2×4) of 21", ≥1600 res (Samsung/LG); many
  prefer larger.
- OS: Windows XP Pro with latest updates.
- Input: standard keyboard + a Cirque glidepad (SmartCat/SmartCatPro,
  USB) — Edward considers it indispensable.
- Vendor example: DigitalTigers (Atlanta) "Stratosphere Elite 5502"
  (Xeon X5560 Nehalem 2.8GHz quad; 64GB Intel X25-E SSD; Zenview Quad
  Elite 24" 3840×2400); total ~$17,000. Other OEM: Colfax International
  (Sunnyvale).

## Advice

Start slowly with an entry-level setup; once familiar with the kit,
expand or fully upgrade to personal specs. One only gets what one pays
for — this is a top-of-line professional setup.

## Key takeaways

1. The method runs on commodity multi-core PCs with SSDs and 8 monitors;
   reliability (mirrored boot, SSD) matters more than peak exotic specs.
