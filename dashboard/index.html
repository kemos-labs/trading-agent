How to read this page

What this is

A control room for a paper-only quant research stack: a knowledge base, a Python toolkit (quantkit), and three backtested strategies. Every number on this page was computed from files on disk when the page was built — nothing is typed in by hand.

The one rule that matters

A signal is decided at today's close and executed at the next bar. If a backtest let today's decision use tomorrow's price, every result here would be fiction. The paper journal enforces the same rule live.

PASS ≠ safe to trade

PASS means a rule cleared a narrow, predeclared test on three ETFs over one holdout. It has not been stress-tested across regimes, purged for overlapping labels, or checked net of realistic slippage. Treat PASS as "still a candidate".

Why there are API keys in another repo

Market data comes from free-tier providers (Massive, Finnhub, Alpha Vantage) whose keys live in a separate project and are read at runtime. They are never copied into this repository, and every call is budget-tracked so a refresh loop cannot burn a quota overnight.

Terms in one line each
  • Sharpe — return per unit of wobble, annualised.
  • Max DD — worst peak-to-trough fall.
  • MAR — CAGR divided by max drawdown.
  • Cost/gross — trading friction as a share of the edge.
  • basis point (bp) — 0.01%; costs here are 10 bp per unit of turnover.
  • holdout — data deliberately kept out of parameter selection.
